# Security Policy

## Supported Versions

This project is under active development. Security fixes are applied to the latest version on the default branch.

## Reporting a Vulnerability

Please report security vulnerabilities privately. Do **not** open a public GitHub issue for security-related reports.

You can report a vulnerability by:

- Using [private vulnerability reporting](https://github.com/yakirgot/household-app/security/advisories/new) on this repository, or
- Emailing **got.yakir@gmail.com**

Please include as much detail as possible (steps to reproduce, impact, and any suggested fixes).

You can expect an acknowledgment within a few days. We will keep you updated on investigation and remediation, and coordinate disclosure once a fix is available.
